\title{Time travelling for dynamic programming}
\author{Alessandro Candolini}
\affiliation{London, UK}
\emailAdd{alessandro.candolini@gmail.com}
\date{\today}
\abstract{%
The call-by-need evaluation strategy of the Haskell programming language enables somewhat ``exotic'' program constructions.
One notable example is the bidirectional state monad known as the Tardis monad%
\footnote{See \url{https://hackage.haskell.org/package/tardis}}.

This note explores how the Tardis monad can be employed to implement an efficient solution to the classical problem of computing the lexicographically maximum subsequence of fixed length $k$ in an array of length $n \geq k$.
The goal is to contribute to the literature of practical usages of the Tardis monad and to support the thesis that the Tardis monad promotes a style of programming in which performance and clarity coexist: the solution performs only a single pass over the input sequence, while the structure of the algorithm closely mirrors the intuitive high-level reasoning behind the problem, rather than the more technical formulations typically found in dynamic programming treatments.
The readability gains are nevertheless bound by the imperative interface of the Tardis monad, and setting the past or future state can also be error-prone.
The problem considered here was motivated by Advent of Code~2025, Day~3
\footnote{See \url{https://adventofcode.com/2025/day/3}}.
}

\section{Preliminary mathematical definitions}
\label{sec:definitions}

Hereafter, $\N$ and $\Z$ denote the set of natural and integer numbers respectively. By convention, $\N$ will include also the element $0$. To avoid confusion, $\N\backslash\{0\}$ will be used to denote explicitly the set of strictly positive integer numbers.

\begin{definition}[sequence]
  Given $n\in\N$ and an arbitrary set $A$, a ``finite sequence'' of length $n$ elements of $A$ is any function $[0, n[ \rightarrow A$.
\end{definition}

In words, a (finite) sequence is any function whose domain is a (finite) interval of natural numbers. The definition can be extended in several ways, none of which are relevant for these handouts. Extensions include: infinite sequences defined as functions $\N\rightarrow A$; functions on (intervals of) $\Z$


A finite sequence of length $n$ of elements of $A$ is commonly denoted with $(a_i)_{i \in [0, n[}$, or when $n$ is clear from the context, more syntetically $(a_i)_i$. The usual notatin for functions $a(n)$ is less often for sequences.

Sometimes, it can be convenient to ``visualise'' the sequence with notations like the following:
\begin{dmath*}
  [a_0, a_1, \ldots , a_{n-1}]
\end{dmath*}

\begin{definition}[subsequence]
  They are given $n\in\N$, a set $A$, and a sequence $(a_i)_i$ of length $n$ of elements of $A$.
  A subsequence of $(a_i)_i$A is any sequence $(a_{i_k})_k$ where $i_k$ is a \emph{strictly increasing sequence of positive integers}.
\end{definition}
